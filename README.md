# 日々のノート

日本語の日記Webアプリのひな形です。日記の作成・編集・削除、日付順の一覧、タイトル・本文の検索に対応しています。画面はスマートフォンでも利用できます。

## 起動

Python 3 と Node.js 20 以上を使用します。依存パッケージのインストールやAPIキーは不要です。

```sh
cd /workspace/nikki
npm start
```

開発サーバーはポート3000で待ち受けます。`npm start` はHTMLを生成してから Python の静的ファイルサーバーを起動します。停止は Ctrl+C です。本番配信には専用の静的ホスティングを使用してください。

`npm run build` で CSS・JavaScript を埋め込んだ単独の `index.html` を生成できます。HTML単体のプレビューでも外部ファイルの読み込みに依存しません。ソースを編集したら再度ビルドしてください。

## テスト

```sh
npm test
```

保存データの読み書き・更新・削除、検索、破損データ・容量不足への対応を検証します。

## 構成と保存先

- `index.html`: 生成済みの単独HTML（直接編集せずビルドする）
- `page.html`: 画面のテンプレート
- `build.mjs`: 依存パッケージ不要のHTML生成
- `style.css`: レスポンシブスタイル
- `app.mjs`: 画面操作
- `storage.mjs`: 保存データと検索

日記はブラウザの localStorage に保存します。サーバーへの送信、ログイン、同期、バックアップ機能はありません。ブラウザのデータ削除で日記も消えます。保存先はオリジン（ホスト・ポート・プロトコル）ごとに異なります。共有端末での機密情報の記録には向きません。

最近のブラウザで使用してください。ストレージが禁止された埋め込みプレビューでは、一時保存モードに切り替わり、その旨を画面に表示します。このモードの日記は再読み込みすると消えます。永続保存を確認する際は開発サーバーから同じオリジンで開いてください。JavaScript自体が禁止されたプレビューでは操作できません。既存の保存データが破損している場合は、上書きを防ぐため保存を停止します。
